# Map Channel

This package ports the existing Taxi map-selection interaction into the universal
Platform Core without importing Taxi UI, React, Leaflet, Redux, or backend code.

- `DefaultMapMapper` maps a selected order ID to the established
  `driver.order.select` InteractionAction.
- `MapChannel` dispatches the action through the existing InteractionContract
  and can observe application Events.
- Invalid or blank order IDs are ignored by the pure mapper.
- Correlation IDs are generated by the channel; timestamps and correlation IDs
  are attached as Interaction metadata.
- The channel is replaceable and contains no business decisions.

The current scope is the interaction boundary only. Rendering the Leaflet map,
route planning, driver lifecycle commands, and Taxi backend adapters remain in
the Taxi application and are not copied into Platform Core.
